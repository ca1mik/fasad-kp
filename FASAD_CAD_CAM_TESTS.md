# Проверка CAD/CAM — 14.10.2026

## Автоматические проверки

Команды из `H:\demo_kp_fasad`:

```powershell
node --test tests/*.test.cjs
py -3.12 -m pytest -q tests --basetemp=tmp\pytest-new-run
```

Последний полный прогон: **23 JavaScript-теста и 221 Python-тест прошли**. Для каждого повторного запуска укажите новый, ещё не существующий путь `--basetemp`. Два предупреждения относятся к устаревшим интерфейсам зависимости `websockets` в тесте серверного портала; отказов нет.

Эталонные тесты проверяют координаты рамки и трёх пазов до/после изменения габаритов, ограничения радиусов и глубин, отверстия/карманы, самопересечение индивидуального контура, преобразования 0/90/180/270°, отдельные стороны проекций, слои SVG/DXF и ограниченный профиль сечения. Независимый `ezdxf` открывает R2000-файл, проверяет миллиметры, 8 дуг скруглённой рамки, геометрию отверстия и отсутствие ошибок аудита. Браузерный тест проходит путь «заказ → чертёж → сохранение → перезагрузка → DXF → карта раскроя», включая отмену/повтор, сетку, масштаб и два экземпляра фасада на листе. Дополнительные проверки подтверждают зазор у двух разных фасадов, ручной поворот/перетаскивание, сохранение координат и совпадение с JSON-черновиком ЧПУ. CAM-тесты проверяют шаги глубины и отказы при неверном сверле, зоне станка, креплении или оборотной стороне.

PDF получен в Edge через печатный режим и проверен рендером страниц в PNG: передний вид на странице 1, задний вид и сечение на странице 2. Проверенный [образец PDF](output/pdf/fasad-cad-sample.pdf) приложен для просмотра. Размеры указаны в мм, но физический масштаб печати зависит от настройки браузера/принтера; применять PDF как шаблон 1:1 без проверки нельзя.

## Пределы тестов

Тесты не доказывают пригодность к резанию на реальном станке. Нет проверки постпроцессора, кинематики, держателей и столкновений инструмента. Нет испытаний фигурного nesting, создания новых листов вручную и синхронизации CAD между браузерами. Эти функции не заявлены реализованными.
